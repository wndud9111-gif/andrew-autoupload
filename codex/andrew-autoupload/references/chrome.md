# Codex Chrome 경로

대상: 데스크톱 로컬 세션 + 연결된 Chrome 확장. 현재 플랫폼 파일럿은 미완료다.

1. 연결된 Chrome의 문서화된 브라우저 도구만 선택한다. 앱 설정의 Chrome 연결·프로필·사이트 권한을 확인한다. 인앱 브라우저로 바꾸지 않는다.
2. 해당 도구가 제공하는 파일 입력 첨부 API와 실제 인수 스키마를 읽는다. Claude 도구명이나 지원되지 않는 setInputFiles 메서드를 추측하지 않는다. 첨부 API가 없으면 미지원으로 보고하고 중단한다.
3. 로컬 테스트 HTML의 upload 입력에 실제 PNG 절대 경로로 첨부한다. 파일 URL 허용과 파일 읽기 권한을 확인한다. OS 파일 선택창을 열지 않는다. 이 문서에 없는 임의 우회 코드를 만들지 않는다.
4. 입력 요소의 파일 정보와 미리보기 로드 결과를 확인하고 텍스트 입력을 점검한다. 성공 도구명·인수·버전·파일 조건을 .preflight.json에 기록한다.
5. 실제 사이트에서는 새 게시물 영역을 열고 그 영역의 파일 입력을 찾는다. 프로필 사진 등 다른 입력과 구분하여 검증한 API로 첨부하고 미리보기·크롭을 확인한다.

로컬 파일 URL 페이지를 읽지 못하면 읽기가 허용된 assets 폴더만 127.0.0.1에 제공하는 임시 서버를 사용할 수 있다. 프로젝트 전체나 로그인 자료를 제공하지 않는다. 파일 URL 허용과 서버 사용은 실제 파일 첨부 권한을 우회하는 수단이 아니다.

| 증상 | 조치 |
|---|---|
| 도구 미연결 | 설정 → Computer Use → Chrome 설치/연결 및 올바른 프로필 확인, @Chrome 선택 |
| 읽기만 가능 | 계획 모드, 파일 읽기 전용 권한, 사이트 조작 승인 대기를 서로 구분 |
| 특정 사이트 불가 | 사이트 차단 목록과 오류 확인, 같은 프로필의 사람 직접 접속과 비교 |
| 파일만 실패 | 파일 URL 허용, 허용된 절대 경로, API의 실제 파일 조건 확인 |

실제 도구명·인수·네이티브 창 미사용은 파일럿 통과 후 이 문서에 확정한다. 현재는 고정된 호출 예시가 없으며, 자동화 성공 검증판으로 배포하지 않는다.

[공식 연결·업로드 안내](https://learn.chatgpt.com/docs/chrome-extension)

명시적인 URL 보안 정책·권한 거부가 나오면 로컬 서버, 다른 URL, 다른 도구로 동일 접근을 재시도하지 않는다. 사용자에게 오류를 보고하고 가능한 원고 작업만 계속한다. 위 임시 서버는 정책 거부가 아닌 정상 지원 환경에서의 로컬 테스트 제공 방법이다.
